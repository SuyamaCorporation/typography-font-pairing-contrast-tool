## Typography Font Pairing & Contrast Design Tool

A live typography preview tool with 20 Google Font pairings. Select a pairing from the dropdown to instantly load the fonts and apply them to an editable preview panel showing H1, H2, body paragraph, and caption. Text in the preview is fully editable inline.

**Tech:** Vanilla JS, Google Fonts (@import via dynamic style tag), WCAG contrast ratio calculation, Tailwind CSS. **How to use:** Choose a font pairing, click any text in the preview to edit it, adjust the background and text color pickers, and watch the WCAG contrast badge update live (AAA/AA/Fail). Click "Copy CSS" to get the font-family and color variable declarations ready to paste into your project.
